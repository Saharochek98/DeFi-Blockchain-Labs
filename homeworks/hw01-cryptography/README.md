# HW1 — Cryptography

**Status:** Student solution completed; instructor review pending.

The assignment covers:

1. Bitcoin private-key collision probability: theoretical estimate and experiments on reduced elliptic-curve groups.
2. Custom educational hash function: determinism, speed, avalanche, uniformity, chi-squared test, collisions and bit balance.
3. Merkle membership proof: generating and verifying an inclusion proof.

The original `solution.ipynb` and `assignment.pdf` are being prepared for upload. Some cryptographic computations require a **SageMath** kernel.
